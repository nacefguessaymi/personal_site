Zenodo: an entry with `zenodo = ` gets its thumbnail, web PDF, and DOI from data/zenodo/.json (generated at build time by scripts/zenodo_fetch.py). Hand-written fields always win; Zenodo only fills in what the entry leaves blank (title, date, event, location, authors). Abstracts stay hand-written — Zenodo's description is raw HTML. Fails the build (rather than rendering an empty page) if the key has no matching data file, so a typo'd slug can't ship silently. Wrapper carries `not-prose` so Blowfish's typography styles don't fight ng/presentations.css. */ -}} {{- $key := .Get 0 -}} {{- if not $key -}} {{- errorf "presentations: missing data key, e.g. presentations \"talks\" (%s)" .Position -}} {{- end -}} {{- if not (isset hugo.Data.research $key) -}} {{- errorf "presentations: data/research/%s.toml not found or empty (%s)" $key .Position -}} {{- end -}} {{- /* Pair each entry with its Zenodo record (if any), then sort. "z" $z "date" (time.Format "2006-01-02" $date)) -}} {{- end -}} {{- $items = sort $items "date" "desc" -}}
